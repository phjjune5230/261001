# DESIGN — 왜 이렇게, 어디로 가나

판단의 방향을 적는 곳입니다. **과거 이력은 여기 두지 않습니다.**
`RULE.md`가 "지켜야 할 것"이라면 여기는 "왜 그걸 정했는지"입니다.

정리를 뒤집으면 여기에 한 줄 남기고 한 줄 고칩니다.

---

## 지금 정해져 있는 것

### provider는 3개, 사용자가 고른다 — OpenRouter · Groq · Gemini
키를 우리가 관리하지 않습니다. 각자 넣고 각자 고릅니다.
SDK로 감싸지 않고 raw `fetch`로 부릅니다 — 프로바이더가 3개뿐이라 추상화가 남는 게 비용입니다.

### 로그인이 없다 — 6자리 PIN 하나뿐
이 앱은 **한 사람이 씁니다.** 처음엔 여러 사람에게 나눠준다고 가정해 Supabase 로그인을
넣었는데, 그 전제를 접고 걷어냈습니다.

그래서 대화 저장은 **서버를 거칩니다.** 브라우저가 DB에 직접 붙으면 안 되니까가 아닙니다.
`NEXT_PUBLIC_` 환경 변수는 번들에 평문으로 실리므로, 브라우저에 키를 주는 순간
"URL을 아는 사람은 이미 갖고 있는" 상태가 되기 때문입니다. anon 키로 RLS를 걸어되
REST API를 직접 호출하면 전부 내려갑니다.

**거쳐서 얻는 것** — anon은 아무것도 못 봅니다. 접근 통로가 `x-app-token` 하나로 좁혀집니다.
LLM 호출과 대화 저장이 같은 검사를 통과합니다.

**대가** — 서버 키는 권한을 완전히 우회합니다. 라우트에서 조건 하나를 빼먹으면
전체 대화가 나갑니다. 그래서 조건은 화면에서 받은 값을 믿지 않고 라우트가 직접 적습니다.

### 컨텍스트는 토큰 예산으로 자른다
턴 수가 아니라 **토큰 수**로 봅니다 — 코드 블록 턴은 수천 토큰이고 "ㅇㅇ"는 몇 개인지 모릅니다.
한글은 글자당 거의 1토큰이라 다른 언어와 다른 계수로 셉니다.
잘린 개수는 화면에 고지합니다 — 사용자가 모르는 상태로 줄어들면 안 됩니다.

**아직 안 된 것.** 자른 것은 **요약하지 않고 버립니다.** 화면과 DB에는 전부 남지만
모델에게는 최근 일부만 보입니다. 그래서 대화가 길어지면 "아까 그 얘기"가 풀리지 않습니다.
압축 요약은 가장 큰 미해결 항목입니다.

### 응답은 비스트리밍이다
전체를 받고 나서 렌더링합니다. 다음 장으로 넘어갈 때 판단해도 늦지 않습니다.

---

## 방향

- 개인 용도. 남에게 나눠줄 일이 생기면 그때 다시 설계합니다.
- 진실은 코드입니다. 문서는 판단의 이유만 적습니다.
- 되돌릴 만한 판단을 먼저 쓰고, 되돌릴 때 한 줄 고칩니다.
